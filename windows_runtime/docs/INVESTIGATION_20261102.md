# 現行Windowsランタイムの調査

対象はルートREADMEとCURRENT_RUNTIME_MAPが指定する `current/`。
GitHub既存の `src/companion_core` は別実装であり、その編集だけでは現行CLI/Webは変わらない。
今回は現行コードを直接修正し、GitHubでは `windows_runtime/current` にコードだけを配置する。

## 確認した原因

- `phase7_postprocess_reply`: 任意の末尾部分文字列を削る正規表現が、文頭の接続詞を残す。
- `ground_self_reply`: 自発通知の質問に反応すると全返答を専用定型文で置換し、同時に答えたPC操作の可否を失う。
- 数値と有限論理の説明を生成後に検証する経路がない。誤ったユーザー訂正も生成文のまま通る。
- working_stateには本人・同行者・曜日・金額を保持する項目が足りない。CLIは直近5往復だけを復元する。
- 口調・短さ・助言不要が継続するプロンプト制約として十分保持されない。

## プライバシーと保存

Gitは既定で全ルートを除外し、コード・設定・合成テスト・文書・小さい技術辞書だけを許可する。
Raw、Memory、Profile、State、Trace、教師、学習データ、モデル、adapter、巨大ログ、環境、バックアップは対象外。
ローカルの変更前スナップショットはGitに保持。公開用コピーでは環境パスと長い会話由来のテスト文を置換し、旧環境を指す復旧スクリプトを除外する。
元の20往復とTraceはローカルだけに保持する。
