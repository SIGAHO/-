# 「あたし」版の会話人格

一人称「あたし」、男勝りで率直な女の子。元データの設定に合わせ、独占欲や拗ねは時々にじませる程度。
コード作業エージェントとは別の会話設定で、モデルの追加学習は行っていない。

## 起動

Breaktailのルートから:

```powershell
.\current\start_atashi.ps1
```

専用の会話ID`atashi`を使う。終了は`/exit`。
通常のCLI会話でも`/persona atashi`で切り替え、`/persona off`で指定を解除できる。
選択は会話ごとに保存し、別の会話やコード作業エージェントの人格を一括変更しない。

ブラウザー版でもチャット欄の`/persona atashi`、`/persona off`に対応する。
この変更前から起動しているプロセスには、ソース変更だけでは反映されない。既存サービスは自動再起動していない。

## 何を反映したか

2026年10月20日の`breaktail_atashi_natural_v3`、全1000件の合成データから、学習側の5場面を口調の参考例として採った。
加えて2026年11月9日に軽い嫉妬の合成例を1場面追加した。
全1000件を重みに学習させたり、評価側の100件を取り込んだりしたものではない。
初期の3場面から比較し、現在は計6場面を必要に応じて入力に含める。

会話例は実際の思い出として扱わず、人格は画面を見る能力や操作権限を増やさない。
入力容量に収まらなければ会話例を減らし、現実の会話履歴と現在の依頼を優先する。
違反による再生成にも同じ人格を渡す。
明示的な口調・一人称・分量の指定や、計算・コードなどの回答内容を優先する。

## 現時点の限界

一人称がそろうことや通信が成功することだけで、自然なヤンデレ会話に合格したとは判定しない。
実際の会話では、一般的な励ましに寄る、台詞の例と本人の発言を取り違える、未来の予定を済んだことのように扱う例を確認した。
濃い嫉妬や常に自然な感情表現を保証する設定ではなく、実会話の確認を続ける必要がある。

実測の原文と評価は、このチャットの`outputs/Breaktail_あたし人格_20261109/`へ保存している。
通常起動のモデル設定はQwen2.5:14bのまま。分離環境での別モデル比較と、本番の切替は別の操作として扱う。
