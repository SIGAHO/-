# 雑談品質の判定を訂正し、返し方を修正

## 前回の評価で不足していたこと

2026年11月3日の347件は機能・構造のテストだった。実会話の完了、文数、禁止事項、計算や人物の照合が通っても、雑談として自然な日本語か、相手の話を正しく受けているかの保証にはならない。これを自然な会話が完成したと扱った報告は訂正する。

生成直後と保存後のTraceを比較すると、不適切な返答は生成段階から存在し、そのまま検査を通過していた。既存の分類器にはユーザー発言を渡しておらず、文脈を取り違えた心理分析を判定できなかった。

## 今回の変更

- 助言禁止の指示に紛れていた「定型的な共感で受け止める」という返し方の強制を外した。助言を足さないことと、笑い話を共感へすり替えることは区別する。
- 雑談用の指示を通常の会話にだけ追加し、具体物や出来事に反応するようにした。機能・コード・創作の依頼には混ぜず、文脈予算を圧迫しないようにした。
- 物を自分になぞらえて笑う発言では、本人が述べていない心理的な落ち込みを追加する返答を検出する。自然な擬人化は残す。実際に述べた感情、否定、冗談とは言えない「笑うしかない」等を区別する。
- 話し方の指定だけには、その指定を受け取った応答を返す。観測していない天気などを勝手に話題として断定しない。具体的な話が含まれる場合はこの確認文で置き換えない。
- 「〜するしかない」という不要な対処法も助言として扱う。独立した末尾の一文ならその文だけを除き、主たる返答や数値の事実を切り捨てない。

## 採用しなかった方法

同じローカルモデルで文脈付きの広い品質判定を試すと、自然な擬人化まで誤って不合格にした。別の校正呼び出しも、良い返答を書き換えて悪くする例があった。この二つは本番経路へ追加していない。実験の失敗はローカルに保存し、成功に数えない。

## 検証の扱い

機能テストと、実際の文章を読む確認を分ける。会話の原文・Traceは公開しない。公開する回帰テストは架空の例で、元の個人的会話は使わない。モデル重み・既存記憶・学習データは変更しない。

機能テストは現行334件＋部品9件＋既存Companion Core11件の354件が成功。元の20往復はローカル2276aaa、最新の別題材8往復と問題箇所の3往復は1a136aaで実行し、保存全文31件を照合した。

問題の取り違えを防ぐ改善は確認したが、別の入力では不自然な語の結びつきや未提示の出来事を追加する返答も残った。日本語品質の全体合格は出していない。詳細な原文はローカルだけに保存し、機能テストの数字でこの失敗を覆い隠さない。
