4. **発話制約: 追加修正済み。** 最終段で口調・一人称・文数・質問・助言・外国語・創作の行動を検査。同じローカルモデルによる意味・日本語の独立審査を追加。最大3回の再生成のたびにgrounding・検算・後処理と再検査を通し、不合格を成功配信しない。今回だけの例外と継続設定を区別する。
