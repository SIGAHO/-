# 理論の振る舞いを検証する実験

実装済みの6系統を、採用前の仮説として実測する。src/ の変更はない。
各系統の hypothesis.md に用途上の期待、cases.jsonl に固定の入力と独立した期待条件を置く。
既知の失敗にも通常のケースと同じ条件を適用し、成功扱いの免除はしない。

## 実行

リポジトリのルートで実行する（Python 3.10以上）。

```bash
python -m pip install -r experiments/requirements.txt
python -m unittest discover -s tests -v
python experiments/run_all.py
python experiments/open_loops/run.py
python experiments/run_all.py --no-write
```

Windows では既存 TimeEngine の ZoneInfo('Asia/Tokyo') に tzdata が必要。
初回、未導入の環境では既存11テスト中4件が時刻データ不足でエラーになった。
tzdata 2026.5 の導入後は既存11件すべて成功した。本体に時刻のフォールバックは追加していない。
通常のIANAデータを持つUnix系環境では追加パッケージは不要。

終了コードは 0 = 全系統PASS、1 = 振る舞い未達あり、2 = 実行・評価エラーあり。
個別 run.py も同じ規則。ケースファイル破損や重複ID等の設定エラーも非ゼロで終了する。
未達があっても他系統を実行し、それぞれ results.json / DECISION.md を更新する。
--no-write は評価だけを実行して保存済み証拠を保持する。

## ケースと判定

ケースは id / reason / 入力 / checks / critical を持つJSONL。
入力形式は runner.py の各アダプターで定義する。記憶の age_days、感情の texts などは
エンジンの実APIに渡す実験条件であり、出力の模倣ではない。

checks は path（辞書のキーとリスト添字をドットで結合）、op、value または other（比較対象のpath）。
eq / ne は不変条件、gt / ge / lt / le は方向や相対比較、range は両端を含む許容範囲、
contains は包含。順位は ranked の先頭や期待する並びを評価する。
全条件成功のケースだけを合格とし、ケース数で合格率を計算する。
数値を実装に合わせて正解にするのではなく、許容範囲や方向をケース側に先に明記する。
記憶ランキングでは時計と寿司のように根拠のない無関係項目間の優劣は要求しない。

採用条件は100%成功かつ実行エラー0件。
PASS はこの集合での支持、REVISE は一部未達、REJECT は成功0件。
critical は権限・曖昧性・訂正などの必須条件を明示するラベルで、通常条件の失敗も免除しない。
実行エラーは別項目で記録し、理論への反証と区別する。
DECISION.md は観測結果から生成され、失敗した条件・期待と実測の差を記録する。
手書きの理由や仮説変更は hypothesis.md / cases.jsonl に残す。

## 再現性と適用範囲

時刻は2026-10-21 09:00 JST、UUIDはケースごとの連番に固定する。
感情係数、訂正ルール、類似度、順位式などの判定処理は置き換えない。
毎ケース新しいエンジンを生成し、状態が他のケースへ漏れないようにする。
results.json は全入力ファイル・実コア・共通ランナーのSHA-256と実行時HEADを記録する。
fixture_time は実験内の時計であり、実際の実行時刻ではない。
実行時HEADとファイルハッシュで対象を特定する。結果をコミットした後はHEADが進むため、
再実行時のsource_commitだけが変わるのは正常。

state では直接の権限・履歴検証に加えて CompanionCore.handle() を通した統合ケースも実行する。
他5系統は実エンジン単体の検証であり、すべての相互作用・Replay・長期関係学習は未検証。
仕様として選んだ期待（空クエリ抑制、曖昧訂正の扱い等）は理論の普遍的正解ではない。
この集合で採用条件を満たしても、未知表現・実会話で追加検証が必要。

本体への自動統合処理は設けない。未達の方式は採用不可として記録し、
新規統合は全系統PASSの終了コード0を必須にする運用とする。
既に実装済みの方式は評価対象として保持し、実験失敗を理由に本体を取り除かない。
修正時は同じケース集合で比較し、新しい境界条件を追加する。
